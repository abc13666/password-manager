# 🔐 Password Manager (Менеджер паролей)

Десктопное приложение для генерации безопасных паролей и их зашифрованного хранения.

## 📸 Скриншоты


## 🚀 Функционал
- **Генератор безопасных паролей:** Используется криптографически безопасная библиотека `secrets`.
- **Сохранение в зашифрованном виде:** Пароли не хранятся в открытом виде, они зашифрованы библиотекой `cryptography`.
- **Копирование в буфер обмена:** Одна кнопка — и пароль у тебя в руках.
- **Удаление записи:** Выбери строку и нажми «Удалить выбранное».

## 🛠️ Технологии
- Python 3.10+
- Tkinter (GUI)
- Cryptography (шифрование данных)
- Secrets (криптографически безопасная генерация)
